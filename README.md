I am a computational astrophysicist studying dark matter: what it is, and how it is distributed in galaxies. I measure it mostly with stellar streams, in the Milky Way and, with large surveys, in thousands of galaxies beyond it.

When a star cluster or dwarf galaxy is pulled apart by its host galaxy, its stars spread out into a long, thin stream. The stream’s path, width and density depend on the host’s gravitational field, including its dark matter. I develop statistical and machine-learning methods to find streams, model them and infer that field, and I write much of the open-source software these analyses run on. I am also a core developer of Astropy, the community Python library for astronomy, where I lead the cosmology module and serve on the Coordination Committee.
